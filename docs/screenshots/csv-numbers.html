When is a CSV cell a number?

what Rust's parse says yes to

str::parse, rustc 1.98
"Nan".parse::<f64>()        Ok(NaN)
"INFINITY".parse::<f64>()   Ok(inf)
"1e400".parse::<f64>()      Ok(inf)
"00544".parse::<i64>()      Ok(544)
"12345678901234567890"
    .parse::<f64>()         Ok(1.2345678901234567e19)
// NaN != NaN; …890 and …891 are the same f64

All correct Rust. All lose what the cell said.

datadiff reads the cell as
Nan          "Nan"
INFINITY     "INFINITY"
1e400        "1e400"
00544        "00544"
12345…890    "12345678901234567890"
100 vs 100.0 equal numbers

A number only if nothing is lost.
